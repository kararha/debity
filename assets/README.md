# Assets Folder

This folder contains app assets.

## Images
Put your app images in `images/` folder:
- Logo
- Splash screen
- Icons
- Illustrations

## Fonts
Download Cairo font from Google Fonts and add these files:
- Cairo-Regular.ttf
- Cairo-Bold.ttf
- Cairo-SemiBold.ttf
- Cairo-Light.ttf

Download from: https://fonts.google.com/specimen/Cairo

1. Click "Download family"
2. Extract the zip
3. Copy the .ttf files to this `fonts/` folder
